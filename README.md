🌟 Mary Hardy — Personal Portfolio Website

A modern and elegant personal portfolio website designed to showcase professional identity, skills, education, and work experience through a clean and visually appealing layout.

🌐 Live Preview

🔗 Website: https://sayeemmahfuz2021.github.io/mary_hardy/

📌 About The Project

Mary Hardy is a professional portfolio website concept focused on simplicity, clarity, and modern web design. It presents personal information, professional skills, educational background, and experience in an organized and user-friendly interface.

The goal of this project is to create a clean online presence that makes a strong first impression.

✨ Features 
🎨 Clean and modern UI design
👤 Personal introduction and About Me section
💼 Professional skills and experience
🎓 Education and resume sections
📱 Responsive layout (if supported by the project)
📩 Contact section
⚡ Lightweight frontend implementation

🛠️ Technologies Used
HTML5
CSS

🚀 Getting Started

To run this project locally:
1.Clone the repository.
2.Open the project folder.
3.Open index.html in your browser.



🎯 Project Goal

To practice frontend development and build a professional portfolio layout using HTML and CSS while improving layout design, typography, spacing, and visual presentation.
